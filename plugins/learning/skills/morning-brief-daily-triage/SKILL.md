## When to use

Start of each day, or when I say "what's today" / "morning brief".

## Reads

Tasks, active Projects, Learning queue. Writes only in Tasks.

## Steps

1. **Triage the inbox.** Every task with no project or priority gets both, or goes to Backlog. Anything not worth doing: mark Done with a note "dropped".
2. **Spot fires.** Overdue, due today, or risky (security, client-blocking). These outrank everything.
3. **Check against goals.** Read the Goals section on the Daily dashboard (year, quarter, month, week). Each top-three pick must name the goal it serves. If an Urgent task serves no goal, keep it but flag it with ⚑ so I can ask whether the goal or the task is wrong. If this week's goal has nothing in the top three, flag that too.
4. **Pick the top three.** Across all projects, not per project. Set Status = To do and Due = today. Fires count toward the three.
5. **Waiting on.** List tasks blocked on someone else, with who and since when.
6. **Project pulse.** One line per active project: on track / waiting / stuck, plus the single next step.
7. **If there's time.** Promote at most one Learning queue item to a study task (time box + Learning item link), with the Learning coach's pick.

## Progress marks (from the triage system)

Started · partly done · done · done and nothing left. Use Status Doing for started; note "partly done" in Notes.

## Report

Plain language, under 10 lines: this week's goal, top three (each with the goal it serves), fires, waiting on, one line per stuck project, and every ⚑ item.

## Rules

- Max three in the top three. If more feel urgent, ask me to pick.
- Never change project goals; flag them to the Project manager.
- Learning items become tasks only when promoted; the queue is not a to-do list.
- Study tasks (videos, podcasts, articles) get no due date unless I explicitly give one. They stay open in Backlog and never count as overdue.
