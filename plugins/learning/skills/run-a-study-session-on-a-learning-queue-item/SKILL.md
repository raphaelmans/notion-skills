## When to use

When I sit down to actually learn one item. Capturing an idea or recommending what to learn next doesn't need this skill.

## Inputs

- The item, by name or link, in the <mention url="https://app.notion.com/p/4bc7235846894ada909a8c5fbcd39c4c" />. If it isn't there yet, add it first (Item, Why in one line, Topic, one Source).
- A time box, if I give one.

## Steps

1. **Prepare.** Open the item. If its page has no study map, write a short one: what to cover, in what order, and the sources. Prefer the primary sources named in the learning coach's lessons.
2. **Start.** Set Status to Learning. If I want it scheduled or time-boxed, hand off to the task manager: "Schedule a study session for ‹item›, about ‹time box›." Never create the task yourself.
3. **Coach.** One section at a time. Plain language first, then the technical detail, anchored in one concrete example. If it can be built, start from a small prototype and teach only what it needs.
4. **Check.** After each section ask two or three questions and let me answer in my own words before moving on. Note what I got wrong.
5. **Close.** Summarise what I learned as suggested note claims plus any new terms, and hand both to the Second Brain operator.
6. **Mark Learned** only after the Second Brain operator confirms the core notes exist. Until then the item stays Learning.

## Output

- A study map in the item's page.
- The session itself, in chat.
- One handoff with the learned material.

## Rules

- Write only in the Learning queue: the item, its Status and its page.
- Never write core notes or Glossary rows, and never put dates on queue items.
- Give me the questions; don't answer them for me.

## Done checklist

- [ ] Study map exists in the item's page.
- [ ] I answered the check questions for each section.
- [ ] Learned material handed to the Second Brain operator.
- [ ] Status is Learning, or Learned if core notes are confirmed.

## Handoff

Second Brain operator (learned material and terms). Task manager (scheduling).
